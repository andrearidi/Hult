# Hult

Hult Complex Decision Making

## Synthetic User Market Needs Simulator

This repository includes a small command line interface for experimenting with
synthetic users and discovering potential market needs.

### Running the simulator

Execute the script and follow the prompts:

```bash
python market_needs_ui.py
```

You will be asked to define each synthetic user (their name and role) and
list any existing needs they already have. The tool will then simulate
simple interactions between all the users and produce a list of new market
needs derived from those interactions.
